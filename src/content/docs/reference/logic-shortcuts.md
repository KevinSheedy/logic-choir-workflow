Default key commands (check *Logic Pro → Key Commands → Edit* if any differ):

| Action | Key |
|---|---|
| Play / stop | `Space` |
| Split at playhead | `Cmd`‑`T` |
| Create marker | `Option`‑`'` |
| Cycle on/off | `C` |
| Show automation | `A` |
| Show/hide mixer | `X` |
| Show Inspector | `I` |
| Bounce | `Cmd`‑`B` |
| Zoom horizontally | `Cmd`‑`←` / `Cmd`‑`→` |
| Zoom to fit selection | `Z` |
| Tool menu | `T` |

Add your own most-used commands here as you discover them.
