## Shortlist (suggested)
1. **Valhalla VintageVerb or Room** ($50): a big upgrade for very little money.
2. **FabFilter Pro-R 2**: if you value a fast, clear UI and plan to buy more FabFilter plugins.
3. **LiquidSonics Seventh Heaven**: if you want *the* classical hall sound and can afford it.

Run each through the [evaluation protocol](/logic-choir-workflow/reverb/evaluation-protocol/) against ChromaVerb and Space Designer before buying.

## ✅ Current choice
**LiquidSonics Seventh Heaven** (bought 2026-10-09). It recreates the Bricasti M7, whose halls are a standard for classical and choral recordings.

### Getting started
1. Install and authorise it, then open Logic. If it doesn't show up, open *Logic Pro → Settings → Plug-in Manager* and rescan.
2. Put it on the reverb **Aux** at **100% wet**, replacing ChromaVerb (see [setup in Logic](/logic-choir-workflow/reverb/why-and-how-much/#setup-in-logic-sendreturn)).
3. Start with the **hall** presets. Set the decay and pre-delay near the [starting values](/logic-choir-workflow/reverb/why-and-how-much/#starting-values) (about 2.2 s and 25 ms), and keep the early reflections low, because the room on the recording already supplies them.
4. Run the [evaluation protocol](/logic-choir-workflow/reverb/evaluation-protocol/) against ChromaVerb and Space Designer. It checks that Seventh Heaven is better *on our recordings* and helps settle on a preset.
5. Note the chosen preset and any changes here and in the concert log.
