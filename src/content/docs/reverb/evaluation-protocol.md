Reverbs all sound good alone. The question is which one sounds best **on our recordings**.

## Setup
1. Pick **two 30–45 s excerpts**: one slow and sustained (the reverb tail is exposed) and one fast and rhythmic (clarity under test).
2. Put each candidate reverb on its **own Aux**, all fed by sends from the same track.
3. Match settings roughly: **decay about 2.2 s, pre-delay about 25 ms**, similar hall type.
4. **Level-match** the returns by ear or with the Loudness Meter, because louder sounds "better".
5. Switch between them blind if possible (ask someone else to toggle the mutes).
