Try these properly **before** buying anything. They're the baseline for the [evaluation](/logic-choir-workflow/reverb/evaluation-protocol/).

## ChromaVerb (algorithmic)
- Modern, low-CPU, with a visual decay display.
- Try the **Concert Hall**, **Church**, **Chamber** and **Smooth Space** room types.
- The **Damping EQ** is useful for shaping the tail.

## Space Designer (convolution)
- Uses **impulse responses** of real spaces. Browse *Large Spaces → Halls / Churches*.
- Very realistic, but it can clash with the real room already on the recording (two different rooms at once).
- Keep **Early Reflections** low and use more of the tail.
