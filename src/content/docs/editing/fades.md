title: Fades
description: Fade-ins, fade-outs and crossfades in Logic.

---

- **Region fades**: drag the top-left or top-right corner of a region with the **Fade tool** (or hover with the pointer tool while holding Ctrl‑Shift in some versions). Set length and curve in the Region inspector (*Fade In / Fade Out / Curve*).
- **Fade-in**: short, **5–50 ms**, just enough to avoid a click at the cut point.
- **Fade-out**: **2–6 s** for applause. Use a gentle curve (logarithmic-ish, curve value around +20 to +40) so it sounds natural.
- **Crossfades** between two regions on the same track: select both, then use the *X-Fade* mode in the Region inspector. Use them when removing a section (e.g. a cough) by editing.
- **Volume automation** (`A` shows it) works too and gives precise control over long fades.
